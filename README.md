# 👁️ BlinkPrint - AI Eye Biometrics & Liveness Authentication System

BlinkPrint is a Web-based AI Liveness Verification system built with Computer Vision to detect eye blinking using Eye Aspect Ratio (EAR) algorithms to prevent spoofing attacks.

## 🚀 Key Features
- **Real-Time Eye Aspect Ratio (EAR):** Powered by Google MediaPipe FaceMesh.
- **Dynamic Liveness Calculation:** Auto-detects eye blinks and updates verification thresholds.
- **Adaptive Security Metrics:** Dynamically assesses confidence scores, verification mode, and security clearance.
- **Futuristic UI:** Built with Neo-Neon Cyber Glassmorphism interface.

## 🛠️ Tech Stack
- HTML5 / CSS3 (Cyberpunk Glassmorphic Theme)
- JavaScript (ES6+)
- Google MediaPipe Face Mesh Engine
